# TravelMate – Full Stack Travel Planning Platform

TravelMate is a **full-stack travel planning web application** developed using **React** on the frontend and **Spring Boot** on the backend.  
The application helps users plan trips, manage itineraries, track expenses, and explore destinations through an interactive and responsive interface.

This project emphasizes **end-to-end full-stack development**, secure authentication, and scalable REST API design.

---

## 🚀 Features

- User authentication using JWT  
- Trip planning and itinerary management  
- Expense tracking for travel budgets  
- Community posts and activity feed  
- Interactive maps for route and location visualization  
- Responsive dashboard for user insights  

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite), JavaScript, HTML, CSS  
- **Backend:** Spring Boot, Spring Security  
- **ORM:** Hibernate (JPA)  
- **Database:** MySQL (production-ready), H2 (development)  
- **Authentication:** JWT  
- **Maps:** Leaflet.js, OpenStreetMap  

---

## 📱 Application Flow

1. User signs up or logs in using JWT-based authentication  
2. Travel destinations and itineraries are fetched via REST APIs  
3. Users create and manage trips and expenses  
4. Interactive maps display routes and locations  
5. Backend services handle data persistence and validation
